DeskPilot — Local-first Desktop Assistant

Quick start:
1. Create a virtualenv and install requirements: `pip install -r requirements.txt`
2. Implement or run `src.app.application` (Task 0.2 will add a minimal PySide6 boot)

Conventions:
- Implementation tasks follow EKO discipline in `tasks.md`.
- UI strings should be Turkish; internal identifiers are English ASCII.

See `tasks.md` for full task plan.
